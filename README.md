## 03 / Research & Projects

### Learning-Based LWE Secret Recovery

**Lattice-based cryptography · Representation learning · Secret recovery**

모듈러 구조를 반영한 입력 표현과 신경망을 활용하여 LWE 비밀키 복구 가능성을 분석합니다.

- 공개 LWE 샘플의 구조를 반영하는 다중 채널 입력 표현 연구
- 합성곱 및 Transformer 기반 비밀키 추론 모델 연구
- 여러 비밀키로 사전 학습한 모델의 미학습 비밀키 복구 가능성 분석
- 타깃 비밀키별 추가 학습 없이 수행하는 직접 복구 방식 연구

### QR Phishing Detection

**Web security · Hybrid analysis · On-device detection**

QR 코드가 연결하는 웹 콘텐츠의 링크와 이벤트를 분석하여 피싱 위협을 탐지하는 프레임워크를 연구했습니다.

- 샌드박스 WebView 기반 정적·동적 분석
- 링크 및 이벤트 정보를 결합한 하이브리드 분석
- 탈중앙 온디바이스 탐지 프레임워크 연구
